# Event Reference Dual Storage: Keep @id Text in Content and Maintain a Reference Index Table

事件引用（手动事件内容中的 `@<id>`，指向另一事件）与标签（ADR-0012）同样采用双存储：`@id` 原文保留在事件内容中，写入时解析进 `event_references` 引用表。v1 中该表唯一的即时消费方是删除提醒（删除被引用事件前查询引用方并提示）；在没有任何服务端消费方的情况下仍选择建表而非纯渲染时解析，是为将来的反向引用预铺服务端索引。页面上的链接渲染从内容原文按与标签一致的边界规则解析，不读取引用表——因此引用表如实记录解析出的所有 id（包括当时已不存在的），消费方只统计能关联到现存事件的行。目标事件被删除后内容文本原样保留，引用成为悬挂引用：保持链接形态，点击时提示事件不存在，写入时不阻止、事后不清除。
