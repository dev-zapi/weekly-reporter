# 时间与时区政策：RFC3339-only wire、偏移承载客户端时区、两端本地化 (2026-11-10)

时间处理原先有三处用户可感知的问题：`wrp --time` 接受不带偏移的 naive 时刻，实际含义由服务器本地时区悄悄决定；输出把 UTC 切片当成本地时间展示且大多不标注；日期参数（`--date`/`--week-start`/`--week-end`/`--month`）的日历语义取决于服务器时区，且服务端三条路径（events 的 `date`、events 的周界、plans/reports）互不一致。结果是同一份数据换一台不同时区的服务器部署，「哪一天」就会移位。本 ADR 固定这次改造之后的长期政策。

**政策五要点：**

1. **Wire 只认 RFC3339 带偏移时刻。** 所有日期/窗口参数（events 的 `date`/`weekStart`/`weekEnd`、plans 的 `date`/`weekStart`/`weekEnd`/`month`、reports 的 `startDate`/`endDate` 与 create/preview 的周界、终版生成 AI 工具的 `startDate`/`endDate`）只接受带 `Z` 或 `±HH:MM` 的时刻；date-only 一律 400，错误信息附合法形态示例。
2. **偏移承载客户端时区。** 窗口取整、周一规范化与月键折算都按请求自带的偏移计算日历语义，服务端不再有自己的一套时区解释；wrp 与 SPA 把本地日期展开为带本机偏移的零点时刻再上线。
3. **存储不变。** 时刻仍是 unix 秒，周期键仍是 date-only 文本；改造不引入数据迁移，也不改变分页 cursor 形态。
4. **展示两端本地化。** wrp 输出一律按运行系统的时区格式化为带偏移、带秒的 ISO 8601（如 `2026-11-10T14:30:00+08:00`），`TZ` 环境变量即覆盖；SPA 展示维持浏览器本地格式不动。
5. **热力图按查看者时区分组。** 端点新增 IANA 时区名参数（如 `Asia/Shanghai`），服务端按该时区分格，SPA 传浏览器时区。使用 IANA 名而非固定偏移，是因为全年窗口跨 DST 时固定偏移会错位。

切换是原子的：wrp、服务端、SPA、技能文档与全部测试在同一个 PR 内完成，没有兼容层、双形态过渡或版本化端点。

## Considered Options

- **用服务器本地时区当窗口边界 vs 请求偏移**（取请求偏移）：服务器时区取决于部署机器，同一请求换台机器就会落到不同日历日，且无法在测试里稳定断言；请求偏移让结果与部署无关，也让「客户端那一天」成为唯一语义。
- **双形态过渡（date-only 与带偏移并存）vs 原子单 PR 切换**（取原子）：本系统单用户，所有消费方都在本仓库树内，wrp、服务端、SPA、AI 工具与测试可以在一次变更里同步切换；过渡层只会延长歧义存在的时间，并给未来重新引入 date-only 留下借口。
- **命名时区输入（`[Asia/Shanghai]` 形式）vs 只信显式偏移**（取显式偏移）：命名时区会扩大解析面，显式偏移已足够表达一个绝对时刻，DST 由客户端展开日期时处理。
- **服务端统一解释日期 vs 客户端展开日期**（取客户端）：客户端的系统/浏览器时区就是「用户日历」的权威来源，服务端只做偏移换算，不再猜测。

## Consequences

- **已知限制：原稿重算没有创建偏移可依。** `regenerate-source` 只能从存储里的 date-only 周期键重算窗口，因此按 UTC 折算——这至少跨部署确定且可测。完整修复需要持久化创建时的偏移，超出本套票的无迁移约束。
- **已知限制：生成会话暂未注入用户当前偏移。** `query_report_list` 已只收带偏移时刻，但终版生成会话的系统上下文尚未提供用户当前偏移，模型只能照抄工具示例或使用 `Z`，非 `+08:00` 用户在窗口边缘可能差一天。跟进票 #143。
- date-only 周期键继续作为存储与响应的身份形态；禁止在 wire 上重新引入 date-only 作为兼容输入。
- SPA 展示侧零改动；从日期键（date-only 文本形态）重建的本地解析语义仍然正确，因为键是日期，浏览器本地解析即用户日历。
- 展示格式（UTC 切片 → 系统时区带偏移 ISO）属于「系统客户端」词条五条格式定律内的演化，不新增定律；格式本身仍是接口，改动需同步所有上游技能文档。
- 服务器自身时区不再参与任何用户语义：部署在 UTC 容器或任意时区结果一致，测试通过 `TZ` 显式控制客户端时区。
